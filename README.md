## Hola, I'm Albert 👋

I write code and I edit music. Both get written down so someone else can read them later, and that reader is who I think about most.

I grew up speaking Catalan, so I have a soft spot for any language that survives because people keep using it. ❤️

### What I do

- 💻 I write and review code. I maintain [`music_notes`](https://github.com/albertms10/music_notes), a Dart library for music theory. Notes, intervals, scales and chords are types, so the code reads like the theory it describes.
- 🎼 I edit music for publication. It's mostly invisible work, but caring about the small details is what makes it deeply fulfilling for me.
- 🎹 I'm building on my music studies with the organ, and I'm still happily a beginner at plenty of it.

### What I believe

Code should be beautiful, and a reader should leave knowing something they didn't before. Music theory shouldn't be gated either. Harmony is a system you can poke, break and rebuild, whether you read scores or source files.

Editing a score and reviewing a pull request feel the same to me. I read slowly, ask what the reader needs, and cut the rest. Every small choice is something someone will end up relying on.

### Say hello 🌿

Ask me about Neo-Riemannian transformations or about naming things well. Catalan and English both work.
